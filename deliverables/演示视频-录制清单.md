# 演示视频录制清单

## 录制参数

- 分辨率：1920×1080；
- 比例：16:9；
- 帧率：30 或 60 fps；
- 格式：MP4；
- 总时长：3–5 分钟；
- 不出现 API Key、邮箱、手机号、学号、绝对用户路径。

## 必须录制的 AGH 画面

- [ ] AGH 窗口和 `agnes-3.0-flash` 模型名称；
- [ ] `plant_read_state` 返回设备状态；
- [ ] `world_model_plan` 生成 12 小时计划；
- [ ] `highfidelity_verify` 返回 32 场景验证结果；
- [ ] `execute_verified_plan(approved=false)` 返回 `approval_required`；
- [ ] 人工审批动作；
- [ ] `execute_verified_plan(approved=true)` 严格执行 0→11；
- [ ] 12 个真实工单；
- [ ] `plan_status.completed=true`；
- [ ] `calibration_status` 显示 `profit_scale=1.2994`、`failure_bias=0`；
- [ ] `trace_export.valid=true`、41 个事件和最后哈希。

## 建议额外录制

- [ ] Gitee 发行版 `v0.1.0` 页面；
- [ ] Gitee 仓库 README；
- [ ] PPT 最终结果页；
- [ ] C-MAPSS 和 TEP 结果页；
- [ ] 历史 1 次故障和负面结果页。

## 配音方案

### 方案 A：本人配音

最可信。按照 `演示视频-逐页讲解稿.md` 朗读即可。

### 方案 B：AI 中文配音

可以提供稳定普通话男声或女声。需要先配置 ElevenLabs API Key，或者改用系统内置语音。生成后与 PPT 和 AGH 录屏合成 MP4。

## 成片结构

```text
0:00–0:45 问题和目标
0:45–1:45 技术与 AGH 工具链
1:45–2:35 真实 AGH 执行录屏
2:35–3:30 结果、校准和外部验证
3:30–4:00 边界、结论和提问
```
