# 演示视频制作步骤：新手版

## 需要准备的文件

全部在：

`<你的项目目录>\04-演示与发布材料`

需要用到：

- `世界模型维护代理-答辩演示.pptx`
- `演示视频-逐页讲解稿.md`
- `演示视频-录制清单.md`
- `公开内容-Gitee发行版截图.png`

AGH 录屏会保存在：

`%USERPROFILE%\Videos\Captures`

---

## 第一步：先熟悉讲解稿

1. 打开 `演示视频-逐页讲解稿.md`。
2. 从头读一遍，不要背，只要知道每页讲什么。
3. 打开 `世界模型维护代理-答辩演示.pptx`。
4. 按 `F5` 播放 PPT，看一遍动画和页面顺序。
5. 如果 PPT 打开后显示“启用编辑”，点击“启用编辑”。

---

## 第二步：录制真实 AGH 画面

这一步最重要，必须展示真实 AGH 操作。

1. 打开你的 AGH 会话。
2. 确认模型名称为 `agnes-3.0-flash`。
3. 按 `Win + Alt + R` 开始录屏。
4. 按下面顺序操作并让它出现在画面中：

```text
plant_read_state
world_model_plan
highfidelity_verify
execute_verified_plan(approved=false)
人工审批
execute_verified_plan(approved=true)
12 个真实工单
plan_status.completed=true
calibration_status
trace_export.valid=true
```

5. 操作完成后，再按一次 `Win + Alt + R` 停止录屏。
6. 打开：

```text
%USERPROFILE%\Videos\Captures
```

7. 找到最新的 `.mp4` 文件，双击检查能否正常播放。
8. 把文件改名为：

```text
AGH真实执行录屏.mp4
```

如果 `Win + Alt + R` 无法录制：

- 打开“设置”搜索“游戏栏”，打开“使用游戏栏录制游戏剪辑、屏幕截图和广播”；
- 或者告诉我，我帮你换一种录制方式。

---

## 第三步：把 AGH 录屏插入 PPT

1. 打开 `世界模型维护代理-答辩演示.pptx`。
2. 找到“最终真实 AGH 会话结果”那一页。
3. 点击菜单：

```text
插入 → 视频 → 此设备上的视频
```

4. 选择 `AGH真实执行录屏.mp4`。
5. 把视频拖到页面中间。
6. 拖动四角，把视频放大到接近整页，但不要遮住标题。
7. 在视频下方或旁边保留一句话：

```text
真实 AGH 会话：审批后严格执行 0→11
```

8. 保存 PPT，按 `Ctrl + S`。

---

## 第四步：录制 PPT 讲解配音

推荐用 PowerPoint 自带的“录制幻灯片演示”。

1. 打开 PPT。
2. 点击菜单：

```text
幻灯片放映 → 录制幻灯片演示 → 从头开始录制
```

3. 点击“开始录制”。
4. 按 `演示视频-逐页讲解稿.md` 的顺序讲解。
5. 每翻一页，就讲对应页面的配音内容。
6. 讲到 AGH 录屏页时，播放视频，并讲真实执行过程。
7. 全部讲完后，点击“结束录制”。
8. 按 `Ctrl + S` 保存。

录制时注意：

- 不要读错数字；
- 不要在视频里展示 API Key、手机号、学号、邮箱或用户路径；
- 语速放慢，每句话之间停半秒；
- 如果某一页讲错了，可以重新录制那一页。

---

## 第五步：导出 MP4

1. 点击：

```text
文件 → 导出 → 创建视频
```

2. 选择：

```text
全高清 1920×1080
```

3. 选择：

```text
使用录制的计时和旁白
```

4. 点击“创建视频”。
5. 文件名填写：

```text
本科生组-U068-翼智AeroAgent-演示视频.mp4
```

6. 等待导出完成。
7. 打开 MP4 检查：
   - 总时长 3–5 分钟；
   - 有讲解声音；
   - AGH 审批和 12 个工单清楚可见；
   - `completed=true` 和 `valid=true` 清楚可见；
   - 没有隐私信息。

## 如果 PPT 录制失败

可以用 Windows 自带剪辑工具：

1. 先单独录 PPT 画面；
2. 单独录自己的讲解音频；
3. 再单独录 AGH 画面；
4. 用 Clipchamp 把三段素材拼在一起：
   `开始菜单 → 搜索 Clipchamp → 新建视频 → 导入素材 → 拖到时间线 → 导出 1080p`。
