# 请先看：剩余操作顺序

## 1. 发布代码仓库

使用以下任一文件：

- `代码仓库上传包-github.zip`
- `代码仓库-git-bundle.bundle`

推荐在 GitHub 或 Gitee 新建空仓库后上传。发布完成后记录仓库链接。

## 2. 发布公开内容

使用：

- 正文：`演示与发布材料/公开发布内容-可直接复制.md`
- 封面：`演示与发布材料/04-public-cover.png`
- 操作卡：`演示与发布材料/代码仓库与公开发布操作卡.md`

发布后记录平台、链接、截图和日期。

## 3. 完成报名与签名

使用：

- `演示与发布材料/报名系统录入清单.md`
- `演示与发布材料/成员分工与独立完成声明-待签字.docx`

成员确认分工并手写签名。身份字段只在官方系统填写。

## 4. 准备视频

使用：

- `演示与发布材料/演示视频分镜.md`
- `演示与发布材料/世界模型维护代理-答辩演示.pptx`

录制 3–5 分钟视频，展示真实 AGH、审批、12 个工单、`completed=true`、`valid=true`。视频完成后把链接填入提交表单。

## 5. 最终提交

提交文件：

`本科生组-U068-翼智AeroAgent-张子轩.zip`

公开包：

`公共安全版.zip`

答辩与发布材料：

`演示与发布材料/`

提交前确认：

- 仓库链接可打开；
- 视频无需登录即可观看；
- 公开内容有截图和发布日期；
- 两名成员签名完成；
- ZIP 名称正确且不包含隐私信息。
