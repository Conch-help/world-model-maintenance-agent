# 安全护盾优化

## 规则

安全护盾独立于世界模型，在每个动作执行前检查当前设备状态：

- 健康 `< 0.42`：强制维护；
- 健康 `< 0.68`：满负荷降为降载；
- 温度超过环境温度 `+25°C`：满负荷降为降载；
- 已经停机或维护中的设备不重复处理。

验证器和真实执行器使用同一护盾，因此验证与实际执行不会走两套动作规则。
