# 项目说明：世界模型驱动的工业设备预测性维护与调度代理

## 一、项目概述

工业设备维护的核心矛盾不是“预测一个剩余寿命”这么简单：维护太早会增加停机与维护成本，维护太晚会导致故障、能耗和未满足需求；而关键动作如果由模型直接下发，又会引入安全与责任风险。

本项目实现一条完整的 Agent 闭环：

```text
设备状态 -> 动作条件世界模型 -> CEM/MPC 多步规划
-> 独立高保真数字孪生多场景验证
-> AGH 人工审批 -> 执行维护/降载/调度
-> 结果回写与误差评估
```

系统不是把预测结果直接展示给用户，而是把预测、验证、审批、执行和 Trace 串成一条可审计的证据链。

## 二、问题与目标

目标是在三台异构设备的随机退化、热力学、故障和维护经济性环境中，降低：

- 设备故障次数；
- 非计划停机时间；
- 未满足生产需求；
- 维护和能耗成本。

同时满足：

- 设备健康和安全约束；
- 容量与需求约束；
- 关键动作必须经过独立高保真验证和人工审批；
- 所有工具调用和动作必须可追溯。

## 三、技术方案

### 3.1 动作条件世界模型

使用 5 个独立 NumPy MLP 组成集成模型，输入设备健康、温度、振动、停机状态、需求、电价、时间和联合维护动作，预测下一步设备状态、产量和单步利润。集成标准差表示预测不确定性。

训练数据来自独立随机数字孪生，不来自正式测试场景。模型在未见种子上进行误差和覆盖率评估。

### 3.2 CEM/MPC 规划器

CEM 搜索未来 24 小时的联合动作，包括：

- full：满负荷生产；
- derate：降载；
- off：停机；
- maintenance：预防性维护。

目标函数同时考虑预测利润、健康风险、预测不确定性和容量约束。

### 3.3 独立高保真数字孪生

数字孪生包含连续退化、热力学、振动、随机故障、维护停机、需求、电价和设备容量。验证时复制当前物理状态，但替换未来随机流，并在 32 个独立场景上取平均，避免把正式回合的私有随机数变成 oracle。

### 3.4 AGH 工具与审批

MCP 工具层包含：

1. `plant_read_state`
2. `world_model_plan`
3. `highfidelity_verify`
4. `request_maintenance_action`
5. `execute_verified_plan`
6. `plan_status`
7. `calibration_status`
8. `trace_export`

动作执行有两道硬门：

1. 计划必须经过高保真验证且 `all_pass=true`；
2. 必须显式传入人工批准 `approved=true`。

Trace 使用 SHA-256 哈希链，任何历史事件或 payload 被修改都会导致 `valid=false`。

## 四、结果

在 10 个未见随机种子、每个 168 h 的测试中：

| 策略 | 平均利润 | 相对阈值维护 | 平均故障 | 停机时间 |
|---|---:|---:|---:|---:|
| 全速生产、无维护 | -81,081 | -187.4% | 23.1 | 175.2 h |
| 固定间隔维护 | -29 | -100.0% | 20.1 | 155.0 h |
| 阈值维护 | 92,815 | 基线 | 7.0 | 39.5 h |
| 世界模型规划 | 119,559 | +28.8% | 8.4 | 64.6 h |
| 世界模型 + 高保真验证 | 111,943 | +20.6% | 9.3 | 71.4 h |

世界模型一步预测：

- 健康 RMSE：0.0191；
- 全机状态 RMSE：0.0456；
- 单步利润 MAE：319.9；
- 集成覆盖率：94.56% (1σ)、97.07% (2σ)。

正式决策采用高保真验证版本。世界模型规划版本用于衡量模型规划上限；验证版本牺牲部分纸面利润，换取独立数字孪生批准和 0 容量违反。

## 五、创新点

1. 从“预测维护”升级为“动作条件世界模型 + 多步规划”；
2. 使用独立未来随机流进行数字孪生验证，避免 oracle leakage；
3. 将 CEM/MPC、集成不确定性和异常降级统一在一套 Agent 工具中；
4. 关键动作经过 AGH 人工审批和哈希链 Trace；
5. 用正常、边界、失败三类测试和未见过种子验证，不只展示单个成功案例。

## 六、真实 AGH 最终闭环

最终真实会话使用 `agnes-3.0-flash`，以计划级人工审批执行 `execute_verified_plan(approved=true)`，严格完成 `0→1→…→11`：

- 12/12 步真实工单；
- 实际利润 14529.53；
- 实际故障 0；
- 验证利润 11181.30；
- 安全护盾调整 9 次；
- `plan_status.completed=true`；
- Trace `valid=true`，41 个事件；
- `calibration_status`：`profit_scale=1.2994`、`failure_bias=0`。

历史未加护盾会话曾发生 1 次故障，该负面样本仍保留在 `docs/AGH_EVIDENCE.md`，用于支撑安全护盾和人工审批的必要性。

## 七、当前限制

当前高保真环境是自建独立数字孪生，不是现场 PLC/DCS 或真实产线数据。它可以提供可控的连续退化和故障真值，但不能替代真实工况验证。本次提交不包含现场 PLC/DCS 或工业授权数据；现场接入仅作为未来扩展。

真实 `agnes-3.0-flash` AGH 会话已经完成，最终安全护盾回合实现 12/12 步、实际利润 14529.53、0 故障和 Trace `valid=true`。主环境仍是独立数字孪生，不是现场 PLC/DCS；该项是当前外部有效性提升的主要边界。
