# PLC / DCS 未来扩展契约（本次不执行）

## 当前边界

本项目本次提交明确不包含现场 PLC/DCS 硬件和工业授权数据的实际接入；以下仅保留未来扩展契约和测试边界：

- OPC UA、Modbus TCP 或现场网关负责实际读写；
- 本项目只发出维护/降载/关机请求；
- 控制器仍负责急停、联锁、安全逻辑和实时保护。

## 命令前置条件

真实命令必须同时满足：

1. `watchdog_ok=true`；
2. `emergency_stop=false`；
3. `maintenance_permission=true`；
4. 有真实 `approval_id`；
5. 有完整 `trace_id`；
6. 动作模式在允许集合中；
7. 执行预算不超过 4 小时。

任何条件不满足，命令必须被拒绝，而不是降级为自动执行。

## 接口映射

- 设备健康、温度、振动、需求、电价 -> 只读寄存器；
- 维护请求 -> 写线圈或受控写入寄存器；
- 每次写入携带审批号和 Trace 号；
- 真实动作返回结果后写回执行结果；
- 控制器必须保留自己的本地急停和联锁。

## 文件

- `src/wm_maint/adapters/plc_contract.py`：命令校验和内存测试适配器；
- `tests/test_plc_contract.py`：急停、审批、权限、模式校验。
