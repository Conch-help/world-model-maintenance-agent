# 风险感知优化结果

## 优化内容

普通验证规划器按平均利润选择计划。稳健规划器同时考虑：

- 利润 CVaR10；
- 故障概率；
- 故障 P90；
- 未满足需求 P90；
- 最大容量违反；
- 世界模型不确定性。

目标函数：

```text
RobustScore =
    profit_cvar10
    - 3000 × failures_p90
    - 80 × unmet_p90
    - 900 × capacity_violations_max
```

## 10 个未见种子对比

| 指标 | 普通验证规划 | 稳健验证规划 | 变化 |
|---|---:|---:|---:|
| 平均利润 | 110273.98 | 108457.24 | -1.65% |
| 平均故障数 | 9.40 | 8.40 | -10.64% |
| 停机小时 | 73.8 | 65.4 | -11.4% |
| 最终设备健康 | 0.8995 | 0.9394 | +4.4% |
| 故障概率均值 | 82.10% | 78.30% | -3.79 个百分点 |
| 故障 P90 | 2.67 | 2.26 | -0.41 |
| 利润 CVaR10 | -2040.99 | 2801.59 | +4842.58 |
| 规划利润 WAPE | 30.30% | 19.56% | -35.5% |
| 容量违反 | 0 | 0 | 不变 |

## 结论

稳健规划器用约 **1.65% 的平均利润**换取了：

- 更高的利润尾部下限；
- 更少的平均故障；
- 更低的 P90 故障；
- 更低的停机时间；
- 更高的最终设备健康；
- 明显更低的规划利润误差。

它没有把风险降到零，但已经证明：**把 CVaR 和故障分位数纳入计划选择，可以改善真实执行的安全性和稳定性。**
