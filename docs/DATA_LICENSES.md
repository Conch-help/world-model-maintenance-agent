# Data and License Notes

## Project Code

MIT License, see `LICENSE`.

## NASA C-MAPSS

- Public NASA prognostics benchmark.
- Citation: Saxena et al., Damage propagation modeling for aircraft engine run-to-failure simulation, PHM 2008.
- The repository stores scripts and result summaries, not the raw dataset.

## Tennessee Eastman Process

- Source used: `Blound04/tennessee-eastman-dataset`, MIT.
- Original model references: Downs & Vogel (1993); Bathelt, Ricker & Jelali (2015).
- TEP is a public process-simulation benchmark, not real production DCS data.

## DAYPSCI v1

- No verifiable public original dataset or license was found.
- The repository provides an adapter and fail-closed tests only.
- Actual validation requires authorized files with labels and a documented license.

## PLC-BEAD

- PLC program and compiled-binary corpus.
- It is not dynamic process time-series data and is not used for scheduling validation.
