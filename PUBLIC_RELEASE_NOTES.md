# Public Release Notes

This public release contains source code, tests, digital-twin configuration, sanitized AGH summary evidence, external validation reports and submission materials.

It intentionally excludes raw AGH sessions, API keys, tokens, local secrets, student identity data, absolute user paths and unauthorized PLC/DCS data.

Boundary statement: TEP is a public process simulation; C-MAPSS is a public degradation benchmark; virtual Modbus is not a real PLC/DCS test; DAYPSCI validation waits for authorized files.
